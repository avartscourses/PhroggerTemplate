
# PhroggerTemplate — Unity First Person Template

A simple 3D project developed with **Unity 6.3 LTS** for the *Videogame Design and Development*.

The project demonstrates basic game programming concepts and interaction mechanisms.

## Play Online

[Play Phrogger](https://avartscourses.github.io/PhroggerTemplate/)

**Controls**
- WASD — Move
- Mouse — Look around
- E — Interact with objects
- Esc — Release the mouse cursor

## Download and Open the Unity Project

1. Click **Code → Download ZIP** on this repository.
2. Extract the ZIP file.
3. Open **Unity Hub → Add → Add project from disk**.
4. Select the folder `UnityProject`, which contains `Assets`, `Packages`, and `ProjectSettings`.
5. Open the project using **Unity 6.3 LTS**.
6. Open the `Apartment` scene and press Play.

## Main Features

- First Person movement and camera control
- Raycast-based interactions
- Trigger zones and automatic pickups
- Collectible items and inventory
- GameState for managing resources
- HUD for gameplay feedback

## Using the Template

You can use this project as a starting point for your own game.

Explore the GameObjects and Components, examine the provided C# scripts, and modify the interaction mechanisms to suit your game concept.

The accompanying workshop notes explain the main programming concepts and how the scripts communicate through Unity Components.

## Project Structure

- `docs/` — Playable WebGL version, published through GitHub Pages
- `UnityProject/` — Editable Unity project and C# scripts

The WebGL version is intended for playing and testing. To modify the game, download and open the Unity project in the Unity Editor.
